Pacote Windows x64 completo, com executáveis, Python, dependências e assets incluídos.

1. Baixe **RestauranteLocal-windows-x64.zip** nos arquivos desta versão.
2. Extraia todo o ZIP em uma pasta e execute **Instalar.bat**.
3. Abra **Restaurante Local** pelo atalho da área de trabalho.

Não é necessário instalar Python, Git, uv ou rtk. A instalação prepara os dados e cria o atalho, sem configurar início automático.

O atalho verifica a versão publicada da main antes de abrir, baixa atualizações com backup e preserva os dados. Sem internet, abre a versão instalada. Se o aplicativo já estiver em execução, apenas reabre a interface. Para atualizar manualmente, feche pela bandeja e execute **Atualizar.bat** na pasta instalada.

Programa: `%LOCALAPPDATA%\Programs\RestauranteLocal`. Dados e backups: `%LOCALAPPDATA%\RestauranteLocal`.
